# Local Codex history

Recovered Codex sessions are retained locally at `/Users/astex/.codex/sessions` (73 transcript files; approximately 2.3 GB). They are not copied here, so this repository stays small and the originals remain untouched.

Use `tools/search-local-codex-history.sh list` to list every session, or `tools/search-local-codex-history.sh search 'phrase'` to find a conversation by its contents. The current Codex session can use the same local archive when you ask for a topic, date, or phrase.
